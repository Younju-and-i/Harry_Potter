# 📚 Harry Potter NLP Text Analysis Project

## 1. 📌 프로젝트 개요 (Overview)

본 프로젝트는 해리포터 소설 텍스트를 기반으로 자연어 처리(NLP) 기법을 활용하여  
텍스트 데이터를 구조화하고, 주요 키워드 및 서사 구조를 분석하는 것을 목표로 한다.

### 🎯 분석 목적
- 텍스트 데이터 정제 및 구조화
- 등장인물, 감정, 장소 등 핵심 요소 추출
- 스토리의 의미 구조 및 관계 분석

### 🧩 주요 키워드 카테고리
- 등장인물 (Character)
- 감정 (Emotion)
- 장소 (Place)
- 주문 (Spell)
- 아이템 (Item)
- 관계 (Relation)
- 시간 (Time)

---

## 2. ⚙️ 전처리 과정 (Text Preprocessing)

### 1️⃣ 토큰화 (Tokenization)
문장을 단어 단위로 분리  
예: "Harry went to Hogwarts" → ['Harry', 'went', 'to', 'Hogwarts']

### 2️⃣ 정제 (Cleaning)
- 소문자 변환
- 구두점 제거
- 특수문자 제거

### 3️⃣ 불용어 제거 (Stopword Removal)
- 의미 없는 단어 제거 (the, is, and 등)

### 4️⃣ 표제어 추출 (Lemmatization)
- 단어를 기본형으로 변환  
예: going → go

---

## 3. 🧠 키워드 기반 분석

| 카테고리 | 설명 |
|----------|------|
| 등장인물 | 스토리 중심 인물 |
| 감정 | 이야기 분위기 및 긴장 |
| 장소 | 사건 발생 위치 |
| 주문 | 마법/행동 패턴 |
| 아이템 | 주요 사물 |
| 관계 | 인물 간 연결 |
| 시간 | 사건 발생 시점 |

---

## 4. 🔢 벡터화를 하는 이유

텍스트 데이터는 문자열 형태이므로 직접 계산이 불가능하다.  
따라서 이를 숫자(벡터)로 변환하여 분석 가능하게 만든다.

### 🎯 목적

#### 1️⃣ 수치화
- 텍스트 → 숫자 데이터 변환

#### 2️⃣ 유사도 분석
- 단어 간 관계 파악  
예: harry ≈ ron

#### 3️⃣ 의미 기반 분석
- 단순 단어 → 의미 구조 분석

#### 4️⃣ AI 적용 가능
- 감정 분석
- 분류 모델
- 추천 시스템

---

## 5. 🏗️ 전체 처리 흐름

텍스트 입력  
→ 토큰화  
→ 정제  
→ 불용어 제거  
→ 표제어 추출  
→ 키워드 분석  
→ (선택) 벡터화  
→ 결과 도출
